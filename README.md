# TDD Login Practice

## Description
This project demonstrates Test-Driven Development (TDD) for a simple login authentication function.

## Structure
- `src/login.js` → Login logic
- `src/login.test.js` → Test cases covering:
  - Empty fields
  - Invalid username
  - Wrong password
  - Correct login
